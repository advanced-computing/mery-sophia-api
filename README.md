## Lab 4

The purpose of our API is to give users updated data on the air quality in New York City. By inputing the flask url with a backslash at the end, you will get a message welcoming you to our API. By adding '/api/list' to the url, you will get an out put of all the NYC air quality data that has been filtered by the specific parameters denoted in the API code. These filters set limits on the amount of data loaded by the API and returns a json file. If the format is a csv, the API will return 'Invalid Format'.
